# Orbit Lab

A real Newtonian gravity sandbox. Drag to launch a satellite past the star and find the velocity
that closes a stable orbit - with live telemetry (speed, altitude, periapsis, apoapsis, revolutions),
orbit detection, and presets for circular, elliptical, slingshot, and chaotic launches.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/orbit-lab/

Pure client-side HTML/CSS/JS. Inverse-square gravity integrated at 240 Hz with semi-implicit Euler.
